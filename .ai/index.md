## Cross-cutting

| Concern | Where it's handled | Notes |
| ------- | ------------------ | ----- |
| Hosting / deploy | Vercel + hosted Postgres; managed services added additively, no VPS. The nonce limit **trusts the platform's forwarded headers** — re-verify before moving off Vercel | [hosting-and-growth-path](decisions/hosting-and-growth-path.md), [rate-limit-forwarded-header-trust](decisions/rate-limit-forwarded-header-trust.md) |
| Package layout | pnpm workspace; `apps/web` + `packages/rules`, not split further yet | [monorepo-package-shape](decisions/monorepo-package-shape.md) |
| Data store | one Postgres = source of truth; Redis / event store are never a copy of it | [single-source-of-truth-database](decisions/single-source-of-truth-database.md) |
| Rule enforcement | server-side only, server-authored timestamps | [server-side-rule-evaluation](decisions/server-side-rule-evaluation.md) |
| Rule state transitions | one `UPDATE … WHERE <precondition> … RETURNING`, never SELECT-then-UPDATE; zero rows means the precondition failed, not that the request did | [guarded-state-transition](patterns/guarded-state-transition.md) |
| Rule deadlines & timelocks | written and compared with the **database's** `now()` — an app-server `Date` drifts by inter-instance clock skew. Client countdowns are display only | [commitment-window-server-clock](decisions/commitment-window-server-clock.md) |
| Time & history | `occurred_at` (block) vs `observed_at` (detection); stats derived, never counters | [event-time-vs-observation-time](decisions/event-time-vs-observation-time.md) |
| Chain history ingestion | Helius `getTransactionsForAddress` only; a trade is **derived by us** from net balance deltas, never read off a parsed-swap API. Excluded candidates (wrap/unwrap, LST swaps, pure sends/receives) are persisted with a reason, not dropped | [chain-data-source](decisions/chain-data-source.md) |
| Money math | Exact decimal strings via `BigInt` everywhere — pricing, rolling sums, rule evaluation. Never a float. `usd_value NUMERIC(38,12)`, nullable; an unpriceable trade is `null` and **never `0`**, and `null` propagates through every total and verdict | [usd-pricing-source](decisions/usd-pricing-source.md) |
| Reconciliation safety | Idempotent by `(wallet_id, signature)` + `ON CONFLICT DO NOTHING`; per-batch row lock with external pricing kept outside the transaction; cursor advanced only via `GREATEST` to a fully-persisted slot; `baseline_completed_at` is the sole "backfill finished" signal; `lots_built_through_slot` is a second, independent cursor for FIFO lot-matching, backfilled from `trades` (not Helius) when it trails `reconciled_through_slot` | [reconciliation-idempotency](decisions/reconciliation-idempotency.md) |
| Asset tiers | Graded by **market cap** (`STABLE`/`LARGE_CAP`/`MID_CAP`/`SMALL_CAP`/`MICRO_CAP`), never by asset identity. Stamped onto the trade at classification time and never recomputed; unlisted / no `mcap` / flag off all fail closed to `MICRO_CAP` + `classification: 'unknown'`, and classification never throws into the reconcile pipeline | [asset-tier-by-market-cap](decisions/asset-tier-by-market-cap.md) |
| FIFO lot-matching / loss limit | `lot-matching.ts` (pure): draws down a mint's oldest open lot(s) first on disposal, opens a new lot on acquisition; quote mints (SOL/LST/stablecoin) never tracked as a position. A close is loss-limit-eligible only if **every** consumed lot, and the close itself, is after the constitution's `activated_at` — one mixed or pre-activation lot excludes the whole close, never split/prorated ("partial coverage", disclosed in the authoring UI and the status page, not implied as full P&L). Gated end-to-end by `rules.loss_limit_enabled`: off, `evaluateTrade`'s `rolling_loss_usd` case returns `unevaluable('loss_matching_disabled')` (never a false "$0 lost"), and the status page shows the limit as unknown-status rather than clean | [reconciliation-idempotency](decisions/reconciliation-idempotency.md), [constitution-schema](decisions/constitution-schema.md) |
| Baseline vs live trades | The 90-day first-connect backfill is a private record: never evaluated, never in a rolling window, no decision or exclusion events. Enforced in `reconcile-wallet.ts` and in `loadWindowedTrades`' predicate | [reconciliation-idempotency](decisions/reconciliation-idempotency.md) |

| Kill switches / fail-closed / idempotency | `feature_flags` table + `isFeatureEnabled()`; rules in CLAUDE.md → *Safety infrastructure* | [feature-flags-and-kill-switches](decisions/feature-flags-and-kill-switches.md) |

| Caller identity | `resolveSession()` is the **only** answer to "which wallet is this request for" — no route reads an address from a request body; single-use nonce, supersede+consume+insert in one transaction, 30-day sliding expiry inside a 90-day absolute cap | [auth README](../apps/web/src/server/auth/README.md) |
